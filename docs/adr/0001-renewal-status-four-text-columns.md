# สถานะการต่ออายุเก็บเป็น 4 คอลัมน์ข้อความในชีต

Sales บันทึกความคืบหน้าการต่ออายุลง Google Sheet ร่วมกัน โดยรายการหนึ่งอาจถูกต่ออายุซ้ำได้หลายรอบ (สูงสุด 4 รอบ) เราตัดสินใจให้แต่ละรอบเป็น**คอลัมน์แยก**ชื่อ `สถานะครั้งที่1` … `สถานะครั้งที่4` ค่าในช่องเป็นข้อความจากชุดเดียวกัน: *(ว่าง = ยังไม่เริ่ม)*, `รอขอใบราคา`, `กำลังดำเนินการ`, `ต่อแล้ว` — ค่า `ต่อแล้ว` เป็นสัญญาณเดียวที่ทำให้รอบจบ แล้วระบบเริ่มนับรอบถัดไปจากวันหมดอายุชุดใหม่ (คอลัมน์ `กำหนดต่ออายุ` หรือ `วันหมดอายุ` ที่อัปเดต) เหตุผล: ทีมกรอกด้วยตาและมือในชีต ข้อความสถานะอ่านง่ายกว่าวันที่ (วันที่จริงมีคอลัมน์ของตัวเองอยู่แล้ว) และ 4 คอลัมน์แยกเห็นความคืบหน้าทุกรอบพร้อมกันโดยไม่ต้องเขียนสูตรในชีต

## Considered Options

- **4 คอลัมน์ข้อความ (เลือก)** — อ่านง่ายทั้งคนและ parser, ชุดคำสั้นช่วยลด typo
- 4 คอลัมน์เก็บ "วันที่ต่อเสร็จ" — คนต้องแปลง "เสร็จ" เป็นวันที่เอง ข้อมูลพลาดง่าย
- คอลัมน์เดียวมี 4 ช่องย่อย — ชีตทำยาก แยก parse ยากกว่า
- รอเห็นของจริงก่อนตัดสิน — คอลัมน์จะถูกสร้างใช้จริงก่อนระบบเสร็จ; เปลี่ยนรูปแบบทีหลัง = ต้องไปแก้พฤติกรรมการกรอกของ sales ทั้งทีมย้อนหลัง

## Code Snippets / Technical Design

หัวคอลัมน์ต้องพิมพ์ตรงตามนี้ (ระบบ normalize ช่องว่างให้ด้วย — `lib/datasource/row-reader.ts`): `สถานะครั้งที่1`, `สถานะครั้งที่2`, `สถานะครั้งที่3`, `สถานะครั้งที่4`

```ts
// lib/domain/renewal-rounds.ts
export const ROUND_STATUSES = ["", "รอขอใบราคา", "กำลังดำเนินการ", "ต่อแล้ว"] as const;
export type RoundStatus = (typeof ROUND_STATUSES)[number];
export type RoundNumber = 1 | 2 | 3 | 4;

export interface RenewalRound {
  n: RoundNumber;
  status: RoundStatus;
}

/** รอบปัจจุบัน = รอบแรกที่ status ≠ "ต่อแล้ว"
 *  ถ้าทุกรอบเป็น "ต่อแล้ว" แล้ว → return null (หยุดแจ้งเตือนรายการนี้ทั้งหมด) */
export function currentRound(statuses: RoundStatus[]): RenewalRound | null;

/** true = รอบปัจจุบันดำเนินการเสร็จ → หยุดเตือนรอบนี้ */
export function roundDone(round: RenewalRound): boolean;
```

## Consequences

- ก่อนคอลัมน์จริงมีข้อมูล ระบบใช้ **stub**: ทุกรายการถือว่าอยู่รอบ 1 ยังไม่จบ (สลับ implementation ในไฟล์เดียวเมื่อคอลัมน์พร้อม)
- ระบบต้องทนต่อค่าที่พิมพ์นอกชุด (typo) — ถือว่าไม่ใช่ "ต่อแล้ว" และรายงานในหมวด "ข้อมูลมีปัญหา"
- แนะนำตั้ง Data validation (dropdown) 4 ค่าในชีตทั้ง 4 แท็บ เพื่อตัด typo ตั้งแต่ต้นทาง
